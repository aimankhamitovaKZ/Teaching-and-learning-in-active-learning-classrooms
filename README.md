# Enseñanza y Aprendizaje en Aulas de Aprendizaje Activo

Manual interactivo sobre la implementación de aulas de aprendizaje innovadoras en educación superior.

## 📖 Acerca de este proyecto

Este manual proporciona una guía completa para rectores, vicerrectores, decanos, docentes, unidades de infraestructura, centros de enseñanza y aprendizaje, y diseñadores instruccionales sobre cómo diseñar, implementar y evaluar espacios de aprendizaje innovadores en instituciones de educación superior.

## 🎯 Público objetivo

- Rectores y vicerrectores
- Decanos
- Docentes
- Unidades de infraestructura
- Centros de Enseñanza y Aprendizaje (CTL)
- Diseñadores instruccionales

## 📑 Contenido del Manual

1. **Introducción y justificación** - Propósito, público objetivo y relevancia estratégica
2. **Fundamentos conceptuales del aprendizaje activo** - Definiciones, relación entre pedagogía, espacio y tecnología
3. **Aulas de aprendizaje activo: tipologías y modelos** - Perspectiva histórica, tipologías y componentes esenciales
4. **Diseño de aulas de aprendizaje activo** - Principios centrados en el aprendizaje, flexibilidad, inclusión y sostenibilidad
5. **Diseño instruccional para aulas activas** - Alineación de objetivos, metodologías y evaluación
6. **Formación y acompañamiento docente** - Competencias pedagógicas y modelos de formación
7. **Integración institucional** - Alineación estratégica y articulación entre unidades
8. **Implementación paso a paso** - Diagnóstico, objetivos, pilotos y escalamiento
9. **Evaluación del impacto y mejora continua** - Indicadores de éxito y toma de decisiones
10. **Casos y experiencias relevantes** - Lecciones aprendidas y recomendaciones prácticas

## 🌐 Sitio web interactivo

Accede a la interfaz completa en el archivo `index.html`. El sitio ofrece una experiencia interactiva para explorar todos los capítulos del manual.

## 🚀 Cómo usar

1. Abre el archivo `index.html` en tu navegador
2. Haz clic en cualquier sección para explorar el contenido
3. Navega entre las diferentes áreas temáticas según tu rol
